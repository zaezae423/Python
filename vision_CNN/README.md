# 크로메이트 품질 데이터셋 설명

이 폴더의 데이터는 크로메이트 공정의 품질 상태를 나타내는 제품 표면 이미지와 공정 센서 측정값으로 구성되어 있다.

## 데이터 폴더 구조

```text
week11_vision_model/
└─ data/
   ├─ resized/
   │  ├─ 학습/
   │  │  ├─ 정상/
   │  │  └─ 불량/
   │  └─ 테스트/
   │     ├─ 정상/
   │     └─ 불량/
   ├─ Error Lot list.csv
   └─ kemp-abh-sensor-YYYY.MM.DD.csv
```

## 전체 구성

|---|---:|---:|

## 표면 이미지 데이터

이미지는 이미 학습용과 테스트용으로 분리되어 있으며, `정상`과 `불량` 폴더명이 이미지의 클래스 라벨이다.

| 데이터 분할 | 정상 | 불량 | 합계 |
|---|---:|---:|---:|
| 학습 | 1,102 | 59 | 1,161 |
| 테스트 | 276 | 15 | 291 |
| 전체 | 1,378 | 74 | 1,452 |

전체 이미지의 클래스 비율은 다음과 같다.

| 클래스 | 이미지 수 | 비율 |
|---|---:|---:|
| 정상 | 1,378 | 94.9% |
| 불량 | 74 | 5.1% |

정상 이미지가 대부분을 차지하는 불균형 데이터이므로 전체 이미지 수와 클래스별 이미지 수를 구분해서 해석해야 한다.

### 이미지 파일 형식

| 항목 | 구성 |
|---|---|
| 파일 형식 | PNG |
| 세로형 이미지 | 480×720 픽셀, 1,442장 |
| 가로형 이미지 | 720×480 픽셀, 10장 |
| RGBA 이미지 | 1,430장 |
| RGB 이미지 | 22장 |

- 정상 이미지 파일명은 주로 `KEMP_IMG_DATA_번호.png` 형식이다.
- 불량 이미지 파일명은 `KEMP_IMG_DATA_Error_번호.png` 형식이다.
- RGB와 RGBA 이미지가 섞여 있으므로 동일한 색상 채널 형식으로 변환해 사용하는 것이 적절하다.
- 이미지 방향이 대부분 세로형이지만 일부 가로형 이미지가 포함되어 있다.

## 공정 센서 데이터

공정 센서 파일은 `kemp-abh-sensor-YYYY.MM.DD.csv` 형식이며 파일 하나가 센서 수집일 하루에 해당한다.

| 항목 | 값 |
|---|---:|
| 센서 CSV 파일 | 33개 |
| 수집 기간 | 2021-09-06~2021-10-27 |
| 수집일 | 33일 |
| 파일별 행 수 | 1,518행 |
| 날짜별 Lot | 22개 |
| Lot별 센서 측정값 | 69행 |
| 전체 센서 행 | 50,094행 |
| 결측 셀 | 0개 |

수집 날짜는 연속된 달력 날짜가 아니며, 실제 CSV가 존재하는 33개 날짜로 구성된다.

### 센서 CSV 열

| 열 | 설명 |
|---|---|
| `Index` | 날짜별 센서 행 번호 |
| `Lot` | 해당 날짜의 작업 또는 생산 Lot 번호, 1~22 |
| `Time` | 센서 측정 시각. 한국어 `오전`·`오후` 표기가 포함된 문자열 |
| `pH` | 공정의 pH 관련 측정값 |
| `Temp` | 공정의 온도 관련 측정값 |
| `Voltage` | 공정의 전압 관련 측정값 |

센서 변수의 정확한 물리 단위는 파일 안에 별도로 기록되어 있지 않으므로 변수명만으로 단위를 확정하지 않는다.

### 수치형 센서 값 분포

| 변수 | 최솟값 | 평균 | 중앙값 | 최댓값 |
|---|---:|---:|---:|---:|

## Error Lot 데이터

`Error Lot list.csv`는 센서 측정값이 아니라 날짜별로 이상이 기록된 Lot 번호를 정리한 파일이다.

| 열 | 내용 |
|---|---|
| `0` | 센서 수집 날짜 |
| `1`, `2` | 해당 날짜에 이상으로 기록된 Lot 번호 |

빈칸은 센서 값의 결측이 아니라 해당 날짜에 추가로 기록된 이상 Lot이 없다는 뜻이다.

전체 33개 날짜 중 8개 날짜에 9개의 이상 `Date + Lot` 조합이 기록되어 있다.

| 날짜 | 이상 Lot |
|---|---:|
| 2021-09-08 | 20 |
| 2021-09-09 | 5, 16 |
| 2021-09-16 | 4 |
| 2021-09-28 | 16 |
| 2021-10-01 | 21 |
| 2021-10-06 | 6 |
| 2021-10-22 | 3 |
| 2021-10-25 | 16 |

## 데이터 식별 기준과 주의사항

- `Index`와 `Lot` 번호는 날짜마다 반복되므로 단독 고유 식별자로 사용할 수 없다.
- 센서 행은 `수집 날짜 + Index`, Lot은 `수집 날짜 + Lot` 조합으로 구분하는 것이 적절하다.
- `Time`에는 날짜가 포함되어 있지 않으므로 센서 파일명의 날짜와 결합해야 전체 측정 시점을 구성할 수 있다.
- 센서 이상 라벨은 `Error Lot list.csv`의 `Date + Lot` 조합을 기준으로 연결한다.
- 이미지 라벨은 `학습/정상`, `학습/불량`, `테스트/정상`, `테스트/불량` 폴더 구조를 기준으로 한다.
- 이미지 파일명과 센서 CSV에는 두 데이터를 직접 연결하는 명시적인 공통 식별자가 없다.
- 이미지와 센서 데이터를 파일 순서나 행 순서만으로 임의 연결하지 않는다.
